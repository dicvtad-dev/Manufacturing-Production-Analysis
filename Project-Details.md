# Manufacturing & Production Analytics Dashboard

## Project Information

**Project:** Manufacturing & Production Analytics
**Tool:** Microsoft Power BI
**Author:** Divyesh Tadvi

## Project Objectives

* Monitor manufacturing production performance.
* Analyze product quality and rejection rates.
* Evaluate machine performance and downtime.
* Measure Overall Equipment Effectiveness (OEE).
* Support data-driven manufacturing decisions.

1. Production Overview
